\section*{Data and Code Availability}
The data originate from the UCI Gallstone dataset \parencite{uci2025gallstone}. The manuscript source, Python workflow, notebooks, and saved experimental outputs are available at \url{https://github.com/QuyDuong106/INFOSYS722_Experimental}. Completed nested Optuna evidence is stored separately for each model family under \texttt{results/optuna\_MODEL/}; configurations, outer-fold predictions, and trial histories support reproduction of the reported metrics. The completed updated stacking run and its per-patient validation metrics are retained in \path{results/stacking_v3}.
